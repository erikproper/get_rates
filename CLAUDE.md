# get_rates — Claude Code Project

A Go project with two command-line tools that replace a manual clipboard-based portfolio
workflow: `get_rates` scrapes current fund prices and pushes them to Google Sheets;
`push_bnd` reads BND pension-account data from the clipboard and pushes it to a second tab.

Read `../GO_CONVENTIONS.md` for all coding, naming, and commenting conventions.
Read `PROJECT.md` for the full project brief, data sources, and sheet structure.
